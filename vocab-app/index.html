חיבור ל-Claude

בלי מפתח האפליקציה מתרגמת בסיסית ומביאה דוגמאות מהמילון. עם מפתח API מתווספים טיפים לזכירה, משפטים מעולם ההנדסה, תחומים, תשובות שגויות חכמות, הצעות מילים ובדיקת כתיבה. המפתח נשמר רק בטלפון הזה, ואפשר להשיג אותו ב-console.anthropic.com. העלות נקבעת לפי מספר הקריאות.

גיבוי והעברה

הורד גיבוי מדי פעם, כי המילים שמורות רק בדפדפן של הטלפון. כדי להעביר מילים מהגרסה הישנה, העתק משם את הגיבוי והדבק כאן.
